## 📖 О программе

**Диспетчер задач — Anti-Virus Mode** — это расширенная версия стандартного диспетчера задач Windows, дополненная инструментами для первичной диагностики системы на наличие вредоносного ПО.

Стандартный диспетчер показывает процессы, но **не предупреждает** о подозрительных. Эта программа:

- Подсвечивает **маскирующиеся** процессы (вирусы, притворяющиеся системными)
- Проверяет **цифровые подписи** файлов
- Показывает **всё, что стартует при входе** в систему
- Ищет **скрытые процессы** (признак руткитов)
- Позволяет **быстро проверить** подозрительный процесс
- Ведёт **белый список** доверенных программ
- **Мониторит CPU** в реальном времени

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📊 **Список процессов** | Все запущенные процессы с цветовой подсветкой |
| 🚨 **Детектор маскировки** | Находит вирусы, притворяющиеся `svchost.exe`, `explorer.exe` и т.д. |
| 🛡️ **Проверка подписей** | Проверяет цифровые подписи через PowerShell |
| 🚀 **Автозагрузка** | Всё, что стартует при входе (реестр + папка Startup) |
| 👻 **Поиск скрытых** | Сравнение `psutil` ↔ `tasklist` — поиск руткитов |
| 📄 **Экспорт отчёта** | Сохраняет полный отчёт в `.txt` |
| 📋 **Белый список** | Свои доверенные процессы (сохраняется в `whitelist.json`) |
| 🎭 **Случайное имя окна** | При каждом запуске — новое имя (защита от вирусов, которые ищут диспетчеры) |
| 🖥️ **Мониторинг CPU** | Загрузка процессора в реальном времени |
| 🎨 **Тёмная тема** | Удобно для глаз |
